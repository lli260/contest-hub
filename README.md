# 🏆 Contest Hub · 比赛查询与备赛管理平台

基于 Flask + SQLite，内置 20 场高含金量赛事，支持自动爬取 Codeforces / AtCoder 未来赛程、时间轴导航、五维含金量评级。

## 功能

- 🔍 **检索**：时间范围（2/6/12个月）、类别、主办方级别（S/A/B/C）、综合含金量、状态筛选 + 关键词搜索 + 三种排序
- 📅 **时间轴**：页面顶部按日期展示各比赛节点（红=顶级⭐⭐⭐⭐⭐），点击跳转到对应卡片，虚线标记“今天”
- 🥇 **五维含金量评级**：主办方级别35% · 获奖难度25% · 政策挂钩15% · 行业认可15% · 历史积淀10%，详情页有可视化评分条
- 🏷️ **状态标签**：报名中 / 即将截止 / 报名已截止·待开赛 / 进行中 / 已结束 / 长期开放（结束日期已过的比赛不会再误判为报名中）
- 🕐 **数据新鲜度**：每张卡片显示「更新于」日期，超过 60 天未核实标记「可能过期」
- 🕷️ **自动爬取**：Codeforces 官方 API + AtCoder 列表页解析，一键同步未来在线赛并自动去重入库
- ➕ **手动添加**：可自行补充任意比赛并录入五维评分
- ⭐ 收藏 · 📋 参赛计划与任务清单（带进度）· 📝 笔记（自动生成重点）· ⏰ 14天截止提醒

## 使用方法

```bat
# 进入项目目录
cd 项目目录（如 E:\contest-hub）

# 创建虚拟环境（仅首次运行需要）
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate

# 安装依赖（仅首次运行需要）
pip install -r requirements.txt

# 启动
python app.py
```

浏览器打开 http://127.0.0.1:5000

## 目录结构

```
contest-hub\
├── app.py              # 后端（Flask + SQLite）
├── contest.db          # 数据库（首次运行自动创建并写入数据）
├── templates\          # 页面模板
│   ├── index.html      # 比赛列表页
│   └── detail.html     # 比赛详情（计划/任务/笔记）
├── static\
│   ├── style.css       # 样式
│   └── main.js         # 收藏交互
└── venv\               # Python 虚拟环境
```

## 说明

- 预置赛程为参考信息，具体以各官网为准；可在 `app.py` 的 `seed()` 中自行增删比赛数据。
- 删除 `contest.db` 后重启即可恢复初始数据。
